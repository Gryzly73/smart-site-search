«Умный поиск на сайте» — русскоязычный диалоговый поиск по каталогу ПО и оборудования. Покупатель может указать название, описать задачу или попросить подобрать компоненты решения. Поиск учитывает уточнения по лицензии, бюджету и оборудованию, показывает полные и частичные совпадения, отдельно предлагает функционально связанные товары.

Достоверность. Цена, наличие и подтверждённые свойства берутся из одного выбранного оффера предоставленного снимка. Неизвестные условия видны в ответе. Связи каталога описывают назначение товаров. Совместимость конкретных позиций требует подтверждения.

Стек. Python 3.12 и SQLite/FTS5, FastAPI и Uvicorn, Pydantic, RapidFuzz, HTTPX и python-dotenv. Интерфейс на HTML, CSS и JavaScript. Точная выдача работает локально. Для интерпретации и экспертного плана проверен YandexGPT Pro 5.1 через Yandex AI Studio Responses API. Trace показывает фактические операции, токены и стоимость расчёта. Бизнес-аналитика строится по событиям SQLite и маркирует демонстрационные заказы.

Лицензии. Python — PSF-2.0, SQLite — общественное достояние. FastAPI, Pydantic и RapidFuzz — MIT. Uvicorn и HTTPX — BSD-3-Clause. python-dotenv — BSD-3-Clause. Yandex AI Studio — внешний сервис на условиях провайдера. Права на публичный демонстрационный показ предоставленных данных проверяются отдельно.
