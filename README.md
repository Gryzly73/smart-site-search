# Умный поиск на сайте

Python-проект для хакатона на тему «Умный поиск на сайте».

## Локальный запуск

Из корня проекта установите зависимости в Python 3.12 и соберите снимок из локального фида.

```powershell
python -m pip install -e ".[dev]"
python scripts/build_catalog.py --feed Mindbox.yml.gz.xml
python -m uvicorn smart_site_search.api.app:app --host 127.0.0.1 --port 8000
```

Интерфейс доступен на `http://127.0.0.1:8000/`, аналитика на `/analytics`, состояние на `/readyz` и документация API на `/docs`. Параметры локальной БД, каталога и модели приведены в `.env.example`. Для Yandex Cloud выберите `SSS_LLM_PROVIDER=yandex`, укажите `YANDEX_API_KEY`, `YANDEX_FOLDER_ID` и `YANDEX_GPT_MODEL`. Для разрешённого внешнего вызова установите `SSS_ENABLE_EXTERNAL_LLM=1`. Тариф задаётся за миллион токенов в валюте провайдера. При отсутствии тарифа стоимость вызова остаётся неизвестной.

Локальные проверки: `python -m pytest -q` и `node --test tests/ui/ui.test.mjs`. Для live-проверки используйте `Astra Linux Special Edition` и свободное описание восстановления виртуальных машин после отказа дисков. В трассе прямого запроса ожидается `rules`, функционального — `llm`. У встроенного тарифа YandexGPT Pro 5.1 стоимость в рублях с НДС.

## Docker и стенд

`docker compose -f deploy/compose.yaml up --build -d` использует локальный `.env`, подключает снимок в `/catalog` для чтения и отдельный том для runtime SQLite. Compose слушает только `127.0.0.1:8000`. Для проверки смотрите `/readyz`, затем прямой запрос Astra и трассу. Команда `docker compose -f deploy/compose.yaml stop` сохраняет runtime-том.

Параметры проверенного live-варианта в приватном `.env`: `SSS_LLM_PROVIDER=yandex`, `YANDEX_GPT_MODEL=yandexgpt-5.1`, `SSS_ENABLE_EXTERNAL_LLM=1`. Для локальной проверки отказоустойчивости установите флаг в `0` или уменьшите `LLM_TIMEOUT_SECONDS`. Общий бюджет ограничен 18 секундами и двумя вызовами на запрос. При исчерпанной квоте OpenAI 429 `insufficient_quota` сразу переводит запрос на локальный путь. Провайдер задаётся явно.

Для проверки с другого устройства привяжите Uvicorn к приватному адресу интерфейса и откройте `/readyz` с устройства той же сети. При необходимости согласуйте локальное правило firewall для порта и подсети. Для публичного стенда нужны согласованные Linux VM, DNS/TLS и право показа карточек. На VM разместите снимок и ключи приватно, снимок подключите только для чтения. Проксируйте HTTPS к loopback-порту контейнера, проверьте холодный старт и анонимный доступ с внешнего устройства. Каталог, фид, журнал и ключи отсутствуют в Docker-контексте.
